# Contributing

Ideas, fixes and new views are welcome. Fork it, change it, build your own version.

- Open an issue first for anything bigger than a small fix.
- Run `npm test`. Everything has to pass.
- No dependencies: this tool runs on Node alone.
- Never put real names, customer data, hosts or keys in code, tests or examples.
- Your own feeds belong in your own folder (`"adapters"` in `control.json`), not here.

By opening a pull request you agree that your contribution is under the Apache License 2.0
of this repository (section 5), and you confirm that you may contribute it.

Not every contribution gets merged. That is no judgement of your work, and your fork
stays yours. This project is maintained alongside other work, so answers can take a while.
